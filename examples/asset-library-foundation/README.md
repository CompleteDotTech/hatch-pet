# Exact-byte Asset Library foundation fixture

This is an authored procedural engineering fixture: one real triangle OBJ and
its explicit license text. It is not production character artwork or a completed
3D import/render demonstration.

`manifest.json` inventories both files with exact hashes, sizes, roles, origin,
license evidence and unreviewed status. Registration verifies bytes; it does not
claim geometry validation or production approval. See
[the foundation API and traceability](../../references/asset-library-foundation.md).

Run `python scripts/demonstrate_asset_library.py --destination NEW_DIRECTORY`
from the repository root to register, reopen and retrieve the exact source bytes.
