# Self-authored look-development contract fixture

Nine actual resource JSON files, one 2×2 RGBA PNG, and `evidence.json` exercise exact-byte loading, dependency closure, typed graph structure, reusable lights/looks, and immutable material inheritance. The fixture's `provenance.origin` is `procedural-fixture`; its pixel content is self-authored and licensed CC0-1.0.

The evidence pins original resource SHA-256 values and the computed wet-coat effective-material hash. These are contract execution results. No shader, lighting render, image-generation call, production approval, or external adapter conversion is claimed.

Run the Python registry example and validation commands in [the contract reference](../../references/lookdev-contracts.md). `tests/test_lookdev_contracts.py` loads these retained files and independently reopens the actual PNG. The fixture does not replace or modify historical production artwork.
