# Ten practical asset workflows

Generated by `python scripts/generate_presets.py`; validate drift with `--check`.

All demonstrations use deterministic Pillow drawings labeled as fixtures and import them explicitly. The synthetic review records exercise gates only. For real artwork, prepare with the preset, import approved art or use installed imagegen handoffs, validate and visually review before packaging.

Run all: `python scripts/demonstrate.py --all --output-dir output/capability-demos`.

## U01 / assembly

A bracket, post and screw progress from separated parts to an assembled fixture. Keep one orthographic view and constant component dimensions.

**Inputs:** Approved component drawings, dimensions and assembly sequence.

**Constraints:** 96x96 transparent cells; explicit ordered frames; cards

**Review:** Mechanical owner checks order, mating surfaces, tools and safety instructions before real assembly.

**External consumer still needs:** Provide product-specific tolerances, fastener torque and safety instructions; verify printed scale.

```powershell
python scripts/demonstrate.py --preset assembly --output-dir output/assembly-demo
python scripts/hatch.py prepare --run-dir output/assembly-production --profile presets/assembly.json --pet-name assembly --pet-notes "Approved component drawings, dimensions and assembly sequence."
```

Inspect `output/assembly-demo/assembly/export/` and `acceptance.json`; the latter is generated by meaningful checks in `demonstrate.acceptance`, not by creating placeholders.
